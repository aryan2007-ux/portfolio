# Portfolio Website

A modern, responsive portfolio website with smooth animations and interactive features.

## Features

- 🎨 **Modern Design** - Clean and professional layout with gradient backgrounds
- ✨ **Smooth Animations** - Fade-in effects, hover animations, and scroll-based reveals
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- 🚀 **Project Showcase** - Display your best work with beautiful project cards
- 💼 **Professional Sections** - Hero, About, Projects, and Contact sections
- 🎯 **Interactive Navigation** - Smooth scrolling and mobile hamburger menu

## Getting Started

Simply open `index.html` in your web browser to view the portfolio website.

### Customization

1. **Personal Information**: Edit the `index.html` file to update:
   - Your name in the hero section
   - About section text
   - Project details and descriptions
   - Contact information and social links

2. **Styling**: Modify `styles.css` to change:
   - Color scheme (CSS variables in `:root`)
   - Fonts and typography
   - Layout and spacing
   - Animation timings

3. **Functionality**: Update `script.js` to add or modify:
   - Interactive features
   - Animation effects
   - Custom behaviors
